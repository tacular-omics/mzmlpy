# Citation

If you use mzmlpy in your research, please cite the software.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21960079.svg)](https://doi.org/10.5281/zenodo.21960079)

The DOI [10.5281/zenodo.21960079](https://doi.org/10.5281/zenodo.21960079) covers all archived
releases on Zenodo. To cite a specific release, use the version DOI listed on that Zenodo page.

## BibTeX

```bibtex
@software{garrett_mzmlpy,
  author    = {Garrett, Patrick T. and Yates, III, John R.},
  title     = {mzmlpy: Type-safe, lazy mzML reading in Python},
  doi       = {10.5281/zenodo.21960079},
  url       = {https://github.com/tacular-omics/mzmlpy},
  license   = {MIT}
}
```

## CITATION.cff

The canonical citation metadata is
[`CITATION.cff`](https://github.com/tacular-omics/mzmlpy/blob/main/CITATION.cff) in the
repository. GitHub's "Cite this repository" button reads the same file.
